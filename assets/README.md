# NEXVANT artwork

- `nexvant-welcome.png`: original midnight-navy/teal welcome banner with the
  NEXVANT wordmark, Binance Spot assistant subtitle and approval tagline.
- `nexvant-avatar.png`: matching square geometric emblem for Telegram's circular
  profile crop. The app uploads it with the static profile-photo Bot API method.

Both PNGs were created for this project. No other trading bot's logo or Binance
emblem is included. They contain no account, balance, credential or performance
data. The decorative chart is artwork, not a signal or predicted return.

Keep these filenames to replace the artwork. An avatar-content change causes
profile setup to reapply on the next startup; welcome cards read the local banner
each time. Telegram's Menu/chat layout remains native. BotFather `/setuserpic`
can apply the same avatar manually when automated profile setup is unavailable.
